# Tradução fiel — 御讃歌集（改訂版）
# Formato: número|verso / verso / verso ...
1|Fogo, Água e Terra — / o Poder da Trindade / trazendo em Si, / eis que surge / Miroku Ōkami.
2|Para edificar / o Paraíso Terrestre, / brande Seu grande / Poder / Miroku Ōkami.
3|Como chega o ladrão, / às ocultas, / em silêncio / desceu a este mundo / Miroku Ōkami.
4|O Cristo, cuja Segunda Vinda / todos os povos aguardavam, / o Messias / e Miroku / são o mesmo Deus.
5|Deixando para trás / Seu altíssimo Trono, / para a salvação / Miroku desceu / a este mundo.
6|Senão pelo Poder / de Deus, sem precedentes, / como se haveria / de salvar / este mundo terreno?
7|Começa a raiar / a Luz do poderoso Deus: / pó e cisco / desvanecem-se — / que alegria!
8|Por milhares de anos / acumulados e acumulados, / o pó e o cisco — / dissipai-os, purificai-os, / ó Deuses dos Quatro Pilares!
9|Pelo grande Batismo / de Fogo e Água / tudo purificado, / chegou a hora de erguer / o Paraíso Terrestre.
10|Um Plano profundíssimo, / até que se erga / o Paraíso Terrestre — / eis o que foi / a longa história.
11|No longínquo Céu, / junto ao Poço de Manai, / no leito do rio Yasu, / do Juramento nasceram / os oito Deuses e Deusas.
12|Os oito Deuses e Deusas, / fundidos num único / Espírito Divino, / fizeram-se, nesta terra, / Izunome no Kami.
13|Cruzando os céus, / percorrendo as terras, / brande o Poder / de diamante / o Dragão Dourado Izunome.
14|No mundo búdico / nascendo como / Komyo Nyorai, / trouxe a salvação / Izunome no Kami.
15|Se por longas eras / salvou sob a forma / de um Buda, / é porque Ele é / Grande Amor e Grande Misericórdia.
16|O Cinco (izu) é Fogo, / o Três (mi) é Água; / o Cinco e o Três / unidos formam / Izunome no Kami.
17|O Cinco é o homem; / o Três designa / a natureza da mulher — / eis o sentido do vertical e horizontal, / do yin e do yang.
18|Não é homem, / nem tampouco / é mulher — / Kannon, em verdade, / é Izunome no Kami.
19|Livre e sem entraves / é o Poder / que Kannon exerce, / porque Ele é / o Espírito do Dez.
20|Ensinamentos da Noite, / cultura da Noite — / tudo findou, / pois o Mundo da Luz / está prestes a vir.
21|Por milhares de anos / ansiada e esperada, / a Era radiante / da Luz / agora chegou.
22|A noite de inverno / já passou; / as flores sorriem, / cem pássaros cantam — / chegou a primavera.
23|Na Era sem trevas / como haveria aflição? / Não haverá brecha / por onde o mal / venha estorvar.
24|As nuvens hostis / afastaram-se ao longe; / no longínquo / firmamento brilha / a luz do grande Sol.
25|O Céu e a Terra / criados pelo Grande Deus / ficariam até quando / encerrados / nas trevas?
26|Quando se abrir / a Porta de Pedra / do coração de todos, / as trevas deste mundo / hão de se dissipar.
27|A noite negra / chegou / ao seu fim; / já no Oriente soa / o sino da alvorada.
28|O que se chama / Mundo da Grande Luz / é o estado / de um Mundo de Cristal / sem nuvem alguma.
29|Tenuemente / chegou a alvorada / do mundo: / nos confins do Oriente / fixai os olhos.
30|Até a voz dos pardais / no beiral / soa animada, / desde que começou a brilhar / a luz do sol nascente.
31|Ao canto do corvo / da madrugada, ergo os olhos: / tingindo o céu / de rubro, rebrilha / a luz do sol nascente.
32|Tenuemente / clareia o céu / do Oriente, / e canta o galo / anunciando a alvorada.
33|Que a noite / de trevas perpétuas / já passou / ignora, errante, / o rebanho de cordeirinhos.
34|Na noite de lua, / nas sombras escuras, / nascem inúmeros / pecados e máculas — / e não há remédio.
35|Na Era luminosa / do pleno meio-dia, / como haveria / coisas ocultas? / De modo algum.
36|Se no mundo não cessam / a maldade / e as coisas ocultas, / é que a treva perpétua / ainda permanece.
37|Ó vós, habituados / à escuridão da noite, / acautelai-vos: / a luz do Verdadeiro Sol / vos ofuscará os olhos.
38|O céu do coração, / antes escuro, / tal qual / o meio-dia / clareou — que alegria!
39|Perceber / a alvorada / é o sinal / de quem possui / olhos verdadeiros.
40|Até a doença / que me punha / a vida em risco / curou-se — que alegria / imergir na Graça!
41|Só ver minha vida / renascer / já era alegria — / e até a arte da cura / me foi concedida!
42|Ah, a alegria / de ter sido curado / da doença! / Pois não há tesouro / que valha a vida.
43|Nada há no mundo / tão precioso / quanto a vida; / agarrando-me de todo, / prolongarei meus anos.
44|Como deixar / de retribuir / à Graça Divina, / ao pensar na ventura / deste corpo que vive?
45|Sem repreender / sequer este corpo / tão cheio de pecados, / grande ventura / Ele concede em abundância.
46|Por mais que louve, / jamais louvarei o bastante / a Graça Divina — / e é triste não ter / como retribuí-la.
47|Ainda que não chegue / à décima milésima parte / da Graça Divina, / aceitai este / sinal de sinceridade.
48|Se eu esquecesse / a Graça / que me deu a vida, / seria igual / a um animal.
49|Mais do que / a riqueza de bilhões, / alegra-me / ter um corpo / livre de males.
50|Diante do Altar, / a cada reverência, / derramo lágrimas / ao pensar neste corpo / que foi salvo.
51|Só existir / sem males / já é graça imerecida — / e ainda entrei no Caminho / da Salvação: que alegria!
52|Por mais que louve, / não esgoto o louvor / desta grande ventura: / nem pincel nem palavra / podem exprimi-la.
53|Amaldiçoando o mundo, / guardando rancor das pessoas — / daqueles tempos / as nuvens do coração / sumiram sem deixar rastro.
54|Sem meus pais, / que me nutriram, / neste mundo / não existiriam este corpo / nem esta alma, penso eu.
55|Com os irmãos / tornei-me alguém / que vive em harmonia, / desde que recebi / a Luz de Deus.
56|O ser humano / é precioso porque / os muitos favores / grava no coração / e não os esquece.
57|Ao pensar na ventura / de ter sido salvo, / como não retribuir, / dando-me por inteiro, / esmerando o coração?
58|Embora eu seja / igual a um grão / de areia da praia, / aceitai / este sinal de sinceridade.
59|Embora eu seja / alguém sem forças, / pelo Caminho / deixai-me servir, / ó Izunome no Kami.
60|Pelo Caminho, / pelo mundo, pelos homens / somente — / quem nisso pensa sem cessar / é que é nobre.
61|Neste mundo, / forte é quem / esquece de si / e segue até o fim / o Caminho reto.
62|Mesquinho / é o coração / que procura / exibir a todos / os próprios méritos.
63|Sem interesse próprio, / guardando o Caminho reto, / recebe-se / em abundância / a Grande Graça.
64|Quão admirável — / deixar para depois / as coisas de si / e desejar o bem do próximo: / esse coração!
65|Em tudo, / guardando a palavra / "medida", / fácil se torna / viver neste mundo.
66|O homem mau / é fraco, / pois não tem força / para vencer / os muitos pecados.
67|Sem distinguir / altos e baixos, / quem ensina com carinho / é quem atende / à Vontade Divina.
68|Furtar-se / aos olhos alheios / é já o mesmo / que furtar / os bens alheios.
69|O que quer que seja, / suportai / com naturalidade, / e tornai-vos quem / responde com um sorriso.
70|Para erguer um mundo / sem enfermos, / o Deus / da Salvação do Mundo / brande o Seu Poder.
71|Na antiga / Era dos Deuses, / a vida / de todos passava / dos cem anos, dizem.
72|Nos tempos antigos, / quando a vida humana / passava dos cem, / não existia isso / a que chamam remédio.
73|É na obra / de fazer os homens / viverem com saúde / que o Poder de Deus / se vê com clareza.
74|Doença / não há por que haver, / de modo algum, / em quem trilha / o Caminho da sinceridade.
75|Não temais / a doença: / os pecados e máculas acumulados / ela os purifica — / é a Graça de Deus.
76|Sem saber a causa / da doença, / querer curar / a doença — / que tolice humana!
77|A doença / é feita pelo homem; / a saúde / é feita por Deus — / sabei-o, ó gente do mundo!
78|Que mistério! / Ah, que mistério! / Se a prece / for justa, / Ele a atende.
79|A força da hora / que salva o mundo / está, como Deus dispõe, / na Vontade de Deus — / sabei-o bem.
80|Mesmo o que / aos olhos humanos / parece bom / pode não estar conforme / à Vontade de Deus.
81|Como quem passeia / pelos campos da primavera, / alegre está o coração / deste corpo envolto / no manto espiritual de Deus.
82|Qualquer pecado / Ele perdoa, / e qualquer pecado / Ele repreende: / o Deus do Céu e da Terra.
83|Como a mãe / pensa no filho, / às miríades / ama Deus — / quão augusto é Seu Coração!
84|Contemplando / a amplidão do céu, / medito / no Grande Coração / que não conhece limites.
85|Deus / é Amor, é Poder — / então, longe de Deus, / poderia alguém / estar em paz?
86|Desde que conheci / o Amor de Deus / do fundo do coração, / tornei-me alguém / que não conhece a solidão.
87|Como o vasto mar, / de fundo insondável, / é profunda a Graça — / diante dela até os demônios / hão de chorar.
88|Cristo / e Buda hão de louvar / a grandiosa / Obra Divina que é Minha, / lá do Céu onde estão.
89|Algo que se compare / a esta misteriosa / Obra Divina / não há, creio, / em todo o vasto mundo.
90|Este mundo revolto / como juncos ceifados / Eu o corto de vez / e ergo / a Era da Retidão.
91|Com a pequena / sabedoria humana, / como compreender / a grandiosa / Obra de Salvação do Mundo?
92|Minha misteriosa / Obra Divina, / desde a antiguidade, / não se vê nos livros / nem nas tradições.
93|Embora seja / Obra do Grande Deus, / é por meio / de um corpo humano / que Ela salva os homens.
94|Descida / do longínquo Céu, / quão sublime / é a Obra do Deus / da Salvação do Mundo!
95|A doença / purifica / corpo e espírito; / por isso é a suprema / Graça de Deus.
96|O corpo humano, / que Deus fez / saudável — / fazê-lo doente / é grande pecado.
97|O corpo humano / é obra / de Deus, / e não é / obra do homem.
98|Não sabem que a causa / da doença / está nos remédios — / ah, como é difícil / a obra da salvação!
99|Digno de pena / é quem lamenta / a doença, / pois é coisa / de muito se alegrar.
100|Em altos palácios, / vestido de brocado, / e, contudo, / agonizando na doença — / quão digno de pena!
101|Ainda maior / que a alegria / da cura da doença / é a alegria de cultuar / o precioso Espírito Divino.
102|Até a ventura / de ser escolhido, / sem merecer, / como servo de Deus / teve a doença por laço.
103|Com a preciosa vida / que recebi, / de hoje em diante / servirei a Deus / com todas as forças.
104|Desde que entronizei / Komyo Nyorai, / com reverência, / o interior do meu lar / tornou-se luminoso.
105|De hoje em diante / todas as desgraças / hão de sumir: / entronizei / Komyo Nyorai.
106|Os familiares / que ainda vagavam / no mundo espiritual / foram salvos pela Luz de Deus / neste dia.
107|Tornei-me / alguém que ora a Deus; / no mundo espiritual / parentes e antepassados / se alegrarão comigo.
108|Ah, a alegria / da Cerimônia de hoje: / corpo e alma / sinto-os passeando / no Paraíso.
109|O coração / que se curva e ora / diante do Altar / é o sinal de que se abriu / a Porta de Pedra.
110|Que gratidão! / Ah, que gratidão! / Adiante / vejo o caminho / onde a Luz resplandece.
111|Corpo e alma / purificados / pela Luz de Deus, / tornei-me alguém / que vive no Paraíso.
112|Da Grande Obra Divina / que ergue o Paraíso / nesta terra / tornei-me servo — / ó alegria deste dia!
